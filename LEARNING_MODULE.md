# Learning Module: Contronyms, Antonyms, and Rational Numbers

Welcome to this comprehensive learning module! This educational package will teach you about contronyms, graded antonyms, complementary antonyms, and rational numbers, then test your knowledge with a 40-question quiz.

## 📚 What's Included

### 1. [Teaching Content](TEACHING_CONTENT.md)
A comprehensive guide covering four important concepts:

#### Linguistic Concepts:
- **Contronyms**: Words with opposite or contradictory meanings (e.g., "sanction" can mean both approve and penalize)
- **Graded Antonyms**: Opposite words on a spectrum (e.g., hot/cold with warm, cool in between)
- **Complementary Antonyms**: Binary opposites with no middle ground (e.g., alive/dead)

#### Mathematical Concept:
- **Rational Numbers**: Numbers expressible as fractions (e.g., 1/2, 0.75, 3, -2/3)

- 10 questions on Contronyms

## 📊 Quick Reference Guide

### Topic Overview

| Topic | Type | Main Feature | Example |
|-------|------|--------------|---------|
| **Contronyms** | Linguistics | Same word, opposite meanings | "Sanction" (approve/penalize) |
| **Graded Antonyms** | Linguistics | Spectrum of opposites | Hot ↔ Cold (with warm, cool) |
| **Complementary Antonyms** | Linguistics | Binary opposites | Alive ↔ Dead (no middle) |
| **Rational Numbers** | Mathematics | Numbers as fractions | 1/2, 0.75, -3, 2/3 |

### Key Differences: Graded vs. Complementary Antonyms

| Feature | Graded Antonyms | Complementary Antonyms |
|---------|----------------|----------------------|
| **Middle Ground** | Yes (spectrum) | No (binary) |
| **Examples** | hot/cold, big/small | alive/dead, on/off |
| **Intensifiers** | Can use (very hot) | Cannot use (very dead*) |
| **Comparatives** | Yes (hotter, biggest) | No |
| **Negation** | "Not hot" ≠ cold | "Not alive" = dead |

*In literal sense

### Common Contronyms Quick List
- **Sanction**: approve / penalize
- **Cleave**: split / stick together
- **Oversight**: supervision / error
- **Dust**: remove dust / add powder
- **Weather**: withstand / wear away
- **Trim**: cut away / add decoration
- **Bound**: heading toward / tied up
- **Seed**: plant seeds / remove seeds

### Rational Number Checklist
A number is rational if it can be:
- ✅ Written as a fraction p/q (where q ≠ 0)
- ✅ Expressed as a terminating decimal (0.5, 0.75)
- ✅ Expressed as a repeating decimal (0.333..., 0.142857...)
- ✅ Written as an integer (5 = 5/1)

A number is irrational if:
- ❌ It's non-terminating AND non-repeating (π, √2, e)
- ❌ It cannot be expressed as a simple fraction
